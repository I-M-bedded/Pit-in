위치는 Docker 워크스페이스에서 - 아마 PIT-IN?

# easy_handeye2 (캘리브레이션 엔진)
git clone https://github.com/marcoesposito1988/easy_handeye2.git

# ros2_aruco (ArUco 마커 검출) <-요거도 있었던거 같음
git clone https://github.com/JMU-ROBOTICS-VIVA/ros2_aruco.git

# RealSense ROS2 드라이버 (이미 있을듯)
sudo apt install -y ros-humble-realsense2-camera

# 의존성 일괄 설치
rosdep install -iyr --from-paths src

# 일단 이 패키지만 빌드 
colcon build --symlink-install --packages-select my_robot_handeye

# 4. 환경 등록
source install/setup.bash


시작 전 ROS2 확인

# 1. TF 트리 전체 확인 (pdf 생성)
ros2 run tf2_tools view_frames

# 2. 마커 TF가 흐르는지 확인
ros2 run tf2_ros tf2_echo mb_1 marker_0

# 3. 엔드이펙터 TF 확인 (로봇 드라이버 실행 후)
ros2 run tf2_ros tf2_echo mb_1 lpin_1

# 4. TF가 모두 연결됐는지 확인 — 이 명령어가 에러 없이 나오면 캘리브레이션 시작 가능
ros2 run tf2_ros tf2_echo mb_1 camera_color_optical_frame



실행 방법

터미널 1: ros2 launch realsense2_camera rs_launch.py   ← 카메라
터미널 2: ros2 launch my_robot_urdf robot.launch.py    ← 로봇 TF (robot_state_publisher)
터미널 3: ros2 launch my_robot_handeye handeye_calibrate.launch.py   <- 여기서 GUI 떠야함
